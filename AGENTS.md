# Project instructions

- Treat this repository as the permanent authoritative Codex workspace.
- Preserve existing functionality and make focused, reversible changes.
- Never edit application embeds unless the user explicitly requests it.
- Do not deploy an unreviewed or unbuilt DLL.
- Build Win32 Release for C++ changes and report every error and warning.
- Confirm relevant executables are closed before replacing DLLs.
- Verify deployed files with SHA-256.
- Update `docs/STATUS.md`, `docs/HASHES.md`, and `docs/CHANGELOG.md` after verified work.
- Create Git checkpoints before risky work and after successful validation.
