CompuHost V4 Structured Setup Dialog

Clarion 10 integration, migration, callbacks, and testing for the CHTheme release candidate.

Updated August 8, 2026 · ABI 00020000H · Header 256 bytes · Entry 5376 bytes

What the DLL owns

The DLL creates the complete Setup window and its modern controls. Clarion supplies a header plus a flat entry array and receives accepted values through the same array. File/folder browsers, the combined font/style/color popup, dependency display, resizing, hover feedback, and Apply state are handled inside the DLL.

Ownership rule: keep DialogHeader, DialogEntries, and the hidden callback button alive until the dialog closes. Do not close the owning Clarion window while DialogInstance is nonzero.

3. Procedure data and callback control

Declare the header and entry records exactly as defined in the include; do not reorder or shorten fields. Dimension the entry array to the maximum used by the procedure. Also declare DialogInstance, CompletedInstance, ChangedInstance, ChangedEntryID, DialogResult, and DialogStatus as shown in the full sample.

Add one hidden button to the owner window:

BUTTON(''),AT(0,0,1,1),USE(?CHUIComplete),HIDE

The complete, paste-ready structures and routines are in CompuHostV4-StructuredSetup-Sample.clw.txt, installed beside this guide.

4. Open the dialog safely

IF DialogInstance
  MESSAGE('The Setup dialog is already open.')
  CYCLE
END
DO LoadCompuHostSampleData
DO PrepareStructuredDialog
IF CHUI_GetAbiVersion() <> CHUI_ABI_VERSION OR |
   CHUI_GetHeaderSize() <> SIZE(DialogHeader) OR |
   CHUI_GetEntrySize() <> SIZE(DialogEntries[1])
  MESSAGE('CHTheme Structured Setup ABI mismatch.')
  CYCLE
END
DialogStatus = CHUI_ValidateDialog(ADDRESS(DialogHeader),ADDRESS(DialogEntries[1]))
IF DialogStatus <> CHUI_STATUS_OK
  MESSAGE('Structured Setup validation failed: ' & DialogStatus)
  CYCLE
END
DialogStatus = CHUI_OpenDialog(0{PROP:Handle},ADDRESS(DialogHeader), |
                               ADDRESS(DialogEntries[1]),?CHUIComplete{PROP:Handle})
IF DialogStatus > 0
  DialogInstance = DialogStatus
ELSE
  MESSAGE('Unable to open Structured Setup: ' & DialogStatus)
END

5. Complete callback event

Put this in ?CHUIComplete / EVENT:Accepted. Actions and live changes are consumed first because they do not close the dialog.

IF CHUI_ConsumeAction(?CHUIComplete{PROP:Handle},ChangedInstance,ChangedEntryID)
  IF ChangedInstance = DialogInstance
    DO HandleStructuredAction
  END
END

IF CHUI_ConsumeChange(?CHUIComplete{PROP:Handle},ChangedInstance,ChangedEntryID)
  IF ChangedInstance = DialogInstance
    DO HandleStructuredChange
  END
END

IF CHUI_ConsumeCompletion(?CHUIComplete{PROP:Handle},CompletedInstance,DialogResult)
  IF CompletedInstance = DialogInstance
    CASE DialogResult
    OF CHUI_RESULT_APPLY
      DO ApplyStructuredDialog
      DO ApplyCompuHostRuntimeChanges
    OF CHUI_RESULT_OK
      DO ApplyStructuredDialog
      DO ApplyCompuHostRuntimeChanges
      DialogInstance = 0
    OF CHUI_RESULT_CANCEL
      DialogInstance = 0
    END
  END
END

Apply and OK: both copy values back and invoke the same CompuHost runtime update. Apply leaves the dialog open; OK closes it. Cancel: closes without accepting edits made after the most recent Apply.

7. One-button font selection per heading

Keep one Clarion group per CDE heading, pre-populate it, encode the group into the font entry's ordinary Value, and decode it on Apply/OK. No extra ABI structure is needed.

CDEHeadingFont GROUP,DIM(5)
Face             CSTRING(128)
Style            ULONG
Color            ULONG
               END

! Associated text entry has ID 310.
DialogEntries[F].Type = CHUI_FONT
DialogEntries[F].ID = 410
DialogEntries[F].ParentID = 300
DialogEntries[F].DependencyID = 310
DialogEntries[F].DependencyOperator = CHUI_DEPEND_NONE
DialogEntries[F].Caption = 'Heading line 1 font'
DialogEntries[F].Value = CLIP(CDEHeadingFont[1].Face) & '|' & |
                         CDEHeadingFont[1].Style & '|' & CDEHeadingFont[1].Color

The dependency association places a compact FONT... button beside the heading text. The popup intentionally omits size; CDE continues to use its fixed size argument:

CDEResult = CDE_SetBackdropLine(CDE_BACKDROP_LINE_HEADING,BackdropText, |
  CDEHeadingFont[1].Face,60,CDEHeadingFont[1].Color, |
  CDEHeadingFont[1].Style,100)

8. Live change and action handling

Set the live-change flag only on settings that are safe and useful to preview immediately. In HandleStructuredChange, use ChangedEntryID to apply only that setting. For existing selectors such as audio-device discovery, declare a CHUI_ACTION; call the Clarion routine in HandleStructuredAction, then return the selected stable value to the open dialog:

SelectedValue = SelectedAudioDeviceID
CHUI_SetEntryValue(DialogInstance,AudioDeviceEntryID,SelectedValue)

Do not send pointers to Clarion queues or temporary variables. Send stable text values through Value; keep all dynamic queue and device discovery logic in Clarion.

9. Migration sequence

  1. Back up the current CompuHost V4 EXE folder and verify no CompuHost/test process is running.
  2. Install the RC DLL, Clarion import library, include, and sample.
  3. Add the include and MAP imports.
  4. Add the exact procedure structures and hidden callback button.
  5. Copy the sample routines and replace test variables with actual CompuHost globals one group at a time.
  6. Wire existing audio/CDE procedures through action and change IDs; do not open old child dialogs.
  7. Regenerate, clean-build, and verify the DLL hash beside the EXE.
  8. Test Cancel first, then Apply, then OK, then restart persistence.

10. Release-candidate test checklist

  • Open only one Setup instance; owner stays responsive.
  • Resize to minimum and maximum; OK, Cancel, and Apply remain visible.
  • Hover navigation, buttons, dropdowns, and checks; styling remains modern.
  • Exercise two-panel and advanced three-panel pages; no empty panels.
  • Verify dependencies enable/hide correctly.
  • File and folder Browse return only the selected path.
  • Each heading FONT button opens pre-populated; face/style/color return together; preview is visible; size is unavailable.
  • Live-change entries trigger the correct entry ID only.
  • Action entries call Clarion and update the open dialog.
  • Cancel preserves pre-open values; Apply commits and remains open; OK commits and closes.
  • Closing CompuHost is blocked while Setup is open.
